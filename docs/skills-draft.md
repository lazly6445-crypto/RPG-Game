# 스킬·속성 초안 (결정 160·161, 검토용)

> 모두 [제안]·[가정]. 마소 소비·쿨다운·피해 계수·스킬 북 티어는 구현 시 `data/skills.json`에 둔다. 스킬은 무기와 무관, 슬롯 4개에 자유 배치. 연출은 도형 파티클(색·형태·크기·화면 흔들림·히트스톱)로 스킬마다 고유하게 만든다.

## 1. 속성 6종 + 무속성
| 속성 | 색(파티클) | 전투 효과 | 월드 규칙 |
|---|---|---|---|
| 불 | 주황·빨강 | 점화(지속 피해) | 타일 위에서 번짐(기존, 가연물 지도) |
| 물 | 파랑 | 젖음(번개 취약·불 면역 3초) | 물 타일 흐름·샘(기존) |
| 번개 | 노랑·흰 | 마비(짧은 정지), 연쇄 | **전도**: 물/젖은 타일·대상으로 전파 |
| 얼음 | 하늘색·흰 | 빙결(둔화→정지) | **물 타일 → 빙판**, 불이 얼음 녹임 |
| 바람 | 연두·흰 | 밀치기, 투사체 굴절 | **불 번짐 방향·속도 증가**, 연기·가벼운 물체 이동 |
| 대지 | 갈색·황토 | 구속(이동 불가 짧게), 넉백 면역 | **지형 높이 변경**(융기/함몰), 석벽(막힘 높이) |
| 무속성 | 흰·은 | 순수 물리/마력 | — |

## 2. 월드 규칙 상호작용 표 초안 (`data/rules*.json` 확장 후보)
| 조합 | 결과 |
|---|---|
| 불 + 물 | 소화(기존), 증기(짧은 시야 흐림, 선택) |
| 물 + 번개 | 연결된 물·젖은 타일의 모든 대상 감전(피해+마비), 범위 전파 |
| 물 + 얼음 | 물 타일이 빙판이 됨(통행 가능, 미끄러짐), 빙판 위에서 물 흐름 정지 |
| 얼음 + 불 | 빙판/빙결 해제(물로 환원), 빙결 대상 해제 |
| 불 + 바람 | 불 번짐 속도·거리 증가, 바람 방향으로 확산 |
| 얼음 + 바람 | 빙결 범위 확대(눈보라 계열) |
| 번개 + 얼음 | 빙결 대상에 추가 피해(균열) |
| 대지 + 물 | 진흙(이동속도 감소 타일) |
| 대지 + 불 | 불 번짐 방어선(비가연 지형 높이 변경으로 방화선, 기존 규칙 유지) |
| 대지 + 얼음 | 얼음 기둥(석벽의 변형, 선택) |
| 번개 + 바람 | 전격 확산(연쇄 대상 +1, 선택) |

## 3. 스킬 40종 초안 (5계열 × 8)

| 3 | 수탄 | 물 | 투사체, 젖음 부여 + 명중 타일 물 |
