# B25 — 아이소메트릭 시점 전환 사양 (결정 130)

> 표기: **[제안]** · **[가정]**(수치, 플레이로 조정) · **[측정]**. 수치는 `data/iso.json`에 둔다(코드에 박지 않음). 게임 로직·데이터·저장 포맷은 변경하지 않는다.

## 1. 원칙
- 격자 좌표 `(x, y)`와 높이 `h`는 그대로. **화면 투영만 바꾼다.** `Terrain`·`GridMover`·`CombatSim`·`MonsterSim`·`RuleSim`·저장 코드는 수정 금지(필요하면 사유를 기록하고 별도 승인).
- 투영·역변환·깊이 정렬은 **노드 없는 순수 로직**(`IsoProjection`)으로 분리하고 헤드리스 테스트한다. 렌더 코드(`*_draw.gd`)는 이 클래스만 호출한다.
- 단계적 적용: 확인 씬에서 먼저, 통과 후 `game.tscn`. 탑다운 렌더는 `data/iso.json`의 `enabled:false`로 되돌릴 수 있게 한동안 유지 **[제안]**.

## 2. 투영 **[제안]**
- 2:1 마름모 타일. 타일 마름모 폭 `tile_w=32`, 높이 `tile_h=16` **[가정]**. 높이 1단 = 화면 `step_px=8` 픽셀 **[가정]**.
- 화면 좌표: `sx = ox + (x - y) * tile_w/2`, `sy = oy + (x + y) * tile_h/2 - h * step_px`.
- 연속 좌표(캐릭터·몬스터·투사체)도 같은 식. 지면 높이는 서 있는 타일의 `h`(낙하·오르기 중에는 보간).
- 내부 해상도 640×360은 유지하되 화면에 보이는 타일 수가 달라지므로(가로 약 20타일 폭, 세로는 마름모 기준) **해상도 게이트 재측정 필요**: 초당 프레임·청크 로드 범위(`Chunk` 가시 영역 재계산).

## 3. 깊이 정렬 **[제안]**
- 정렬 키: `(x + y)`가 큰 것이 앞, 같으면 `h` 큰 것이 앞. 엔티티는 발 위치 기준.
- 블록 렌더: 윗면 + 좌/우 옆면(절벽면). 옆면은 이웃과 `Δh`만큼 그린다(현재 절벽 띠 로직 재사용 불가 → 신규).
- 지붕 페이드(`RoofFade`)·건축물은 같은 키로 정렬, 플레이어를 가리면 투명화(기존 규칙 유지).
- 가림 문제: 높은 블록 뒤 엔티티는 실루엣 표시 옵션 **[제안, 기본 켬]**.

## 4. 입력 **[제안]**
- 이동 키는 **화면 기준**: W=화면 위(격자 `(-1,-1)`), S=아래(`(+1,+1)`), A=왼쪽(`(-1,+1)`), D=오른쪽(`(+1,-1)`). 동시 입력으로 8방향. 속도는 화면 방향 기준으로 정규화 **[가정]**.
- 마우스 조준/클릭(공격): 화면→격자 **역변환**. 높이가 있으므로 `h` 후보를 위에서부터 검사해 첫 일치 타일 선택(`IsoProjection.pick(sx, sy)`).
- 바라보는 방향·공격 판정 모양: 격자 방향 그대로 쓰되 화면 표시용 8방향으로 매핑.

## 5. 그래픽 (스프라이트 방향 수 — 결정 131: 8방향)
- 캐릭터·몬스터 방향 수: **4방향으로 시작**(사용자 미응답 시 기본), 8방향 확장은 데이터 키로 열어둠 **[가정]**.
- 에셋 파이프라인은 아직 도형(색 블록) 단계다. 이번 전환도 **도형 기반 아이소 블록·캐릭터 플레이스홀더**까지만 만든다(아트 제작은 범위 밖).
- 타일 표현: 지형 종류별 윗면 색 + 옆면 두 톤(밝음/어두움). 물·불·마소 시각화는 기존 데이터를 윗면 오버레이로.

## 6. 영향 받는 코드 (조사 후 확정)
렌더/뷰: `*_draw.gd`, 각 `*_view.gd`(마우스 입력 포함), 카메라, `Hud` 월드 오버레이, `Fog`/`Compass`/`MapData`(미니맵·방위 표시: 방위 회전 반영). 로직 모듈은 불변이 원칙. 구현 전 세션이 목록을 코드에서 직접 확인해 이 절을 갱신한다.

## 7. 단계 **[제안]**
1. **B25a** `IsoProjection` 순수 로직(투영·역변환·정렬 키·`iso.json` 검증) + 테스트.
2. **B25b** 확인 씬 `iso_terrain_view`: 지형 블록 렌더(높이/절벽/깊이 정렬), 이동·카메라·마우스 선택.
3. **B25c** 엔티티(플레이어·몬스터·보스·투사체·효과) 아이소 렌더 + 전투 확인 씬.
4. **B25d** `game.tscn`/월드 전환·HUD/지도/나침반 적용, 스모크 봇 전체 통과.
5. **B25e** 해상도·성능 게이트 재측정(`bench`), 결정 108·111~114 재검토 기록.

각 단계 완료 기준: 기존 헤드리스 테스트 전부 PASS + 신규 테스트 PASS + 해당 단계 스모크 오류·경고 0. 사람이 직접 볼 항목은 `dev-review-queue.md`에 추가한다.
