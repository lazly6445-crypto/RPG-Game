# 아트 바이블 v0 (초안) — 화풍 가이드 + AI 협업 작업 방식

> 결정 187·188. 작성: Claude(사용자는 아트 비전문가). 모든 값은 **[제안]**, 시험 후 확정. 용어는 §1에 먼저 설명.

## 1. 기본 개념 (이것만 알면 대화가 된다)
| 용어 | 뜻 |
|---|---|
| 도트(픽셀 아트) | 아주 작은 화면(우리는 640×360)에 점 하나하나를 의도해서 찍은 그림. 확대해도 번지지 않게 그대로 키운다(nearest). |
| 팔레트 | 쓰는 색의 목록. 색이 적을수록(예: 지역당 16~32색) 그림이 하나로 통일돼 보인다. **화풍의 70%는 팔레트가 결정한다.** |
| 외곽선 | 물체 가장자리 선. 검정 대신 물체 색보다 어두운 같은 계열 색을 쓰면(셀렉티브 아웃라인) 부드럽고 세련돼 보인다. |
| 음영 단계 | 한 물체를 몇 톤으로 칠하는가. 우리는 밝음/중간/어두움 3톤 + 가장 밝은 하이라이트 1톤(최대 4톤). |
| 광원 | 빛이 오는 방향. 게임 전체에서 **왼쪽 위 고정**(그림자는 오른쪽 아래). |
| 프레임 | 애니메이션의 한 장. 걷기 8프레임 = 그림 8장을 돌려 보는 것. 많을수록 부드럽다. |
| 8방향 | 캐릭터가 8방향(상하좌우+대각)을 보는 그림 세트. 5방향만 그리고 3방향은 좌우 반전하는 것이 표준(작업량 5/8). |
| 스프라이트 시트 | 프레임들을 한 장에 격자로 모은 이미지. 게임은 이걸 읽어서 재생한다. |
| 레이어 분리 | 몸/옷/무기/이펙트를 따로 그려 겹치는 것. 장비가 바뀔 때마다 전체를 다시 안 그려도 된다. |

## 2. 세계관에서 뽑은 화풍 키워드 (GDD 기준)
- 톤: **쓸쓸함, 담담함, 설명하지 않는 빈칸.** 축하하는 느낌의 밝은 색은 피한다.
- 색: **차분한 탁한 기본색 + 지역마다 포인트 색 하나.** (화려함은 이펙트와 포인트 색에서만)
- 느낌의 한 줄: *"사람이 떠난 자리에 다른 세계가 겹쳐 들어와 조용히 자라는 풍경."*

## 3. 화풍 제안 (사용자가 직접 고르지 않아도 되게 내가 정함 → 시험 후 수정)
**결론: 시안 A(클린 도트)를 기본으로 + 이펙트·특정 구역에만 B식 발광.** 이유: 감성은 팔레트와 분위기에서 나오고, 클린 도트는 AI 도구가 가장 안정적으로 만들고 사람이 정리하기도 쉽다.

| 항목 | 규칙 |
|---|---|
| 해상도 | 내부 640×360, 타일 2:1 다이아몬드 32×16 |
| 캐릭터 크기 | 약 24~28px 높이(타일 1칸 대비 약 1.6배) — 시험 후 확정 |
| 팔레트 | 전역 공통 16색(회색조·갈색·뼈색) + 지역 포인트 8색 + 이펙트 원소 6색 (§4) |
| 외곽선 | 물체별 어두운 동색, 1px, 지면에 닿은 부분만 생략 |
| 음영 | 3톤 + 하이라이트, 디더링 사용 안 함, 광원 왼쪽 위 |
| 그림자 | 발밑 납작한 타원 1개(반투명 어두운 색) |
| 발광 | 불·번개·마소·요정은 외곽선 밖에 1px 밝은 테두리 + 주변 타일 약한 밝기 (게임 코드에서 처리) |

## 4. 지역 팔레트 방향 [제안, hex는 시험 중 확정]

## 5. 애니메이션 사양 [제안] (프레임을 아끼지 않는다 — 결정 187)
| 동작 | 프레임(방향당) | 비고 |

## 6. AI 도구 협업 단계 (한 번에 한 단계씩, 사용자 개입 최소화)
| 단계 | 누가 | 내용 | 산출물 |
|---|---|---|---|
| 0 | Claude | 이 문서(아트 바이블) + 도구별 입력 템플릿 작성 | `art-bible.md`, `ai-art-prompts.md` ✅ |
| 1 | **사용자(10분)** | 도구 가입(PixelLab 체험 → 안 되면 Retro Diffusion), 아래 프롬프트로 **주인공 컨셉 3장** 생성, 마음에 드는 1장 저장 | 이미지 파일 |
| 2 | Claude | 고른 컨셉으로 팔레트 추출·고정, 외곽선/음영 규칙 점검 보고 | 팔레트 확정안 |
| 3 | 사용자+도구 | 주인공 5방향 대기·걷기 생성 (도구 기능 사용) | 프레임 이미지 |

사용자 판단은 항상 **"사진 보고 느낌이 맞나/틀리나"** 하나로 줄인다. 기술적 설정은 내가 맡는다.
