## 3. 일정·비용 영향 (정성적, 숫자 환산 불가)

**줄어드는 작업:** 3인칭 추격 카메라(충돌·변형 직후 보정·좁은 실내), 3D 모델·리깅·텍스처, 3D 스트리밍, 복셀 저장·메시 생성, 3D 조명·그림자 최적화.
**늘거나 새로 생기는 작업:** 타일셋 제작, 스프라이트 프레임 애니메이션(캐릭터·몬스터), 픽셀 아트 일관성 관리, 탑다운 전투 판정, 타일 레이어/높이 표현의 시각 설계.
**판단:** 1인·파트타임·통합 그래픽 목표에서는 줄어드는 작업이 더 크다고 **추정**하지만 근거 있는 환산은 없다. **일정 단축 방안(결정 27)의 입력은 P0 프로토타입 측정으로 바뀐다:** 월드 크기 축소를 첫 후보로 둔 이유가 3D 비용이었으므로 재평가한다. **[측정]**

## 4. 새로 정해야 할 것 (2D 설계) **[미결정]**

### 4.1 화면 기본 **[확정: 결정 111~114]**
| 항목 | 결정 | 비고 |
|---|---|---|
| 투영 | **탑다운(3/4 뷰)** (결정 111) | 컨셉 원본의 아이소메트릭은 채택하지 않음. 타일 편집·충돌·제작이 단순 |
| 타일 크기 | **32px** (결정 112, P0 화풍 실험에서 조정 가능) | 스프라이트·타일셋 제작량이 16px보다 크게 늘어남 |
| 기준 해상도 | **640×360**(약 20×11타일, 1080p에 3배 정수 확대) (결정 113) | |
| 스프라이트 방향 수 | **8방향** (결정 114) | 4방향 대비 프레임 수가 약 2배에 가까워질 수 있음. 아래 경고 |

**경고 [제안]:** 32px 타일과 8방향은 둘 다 **제작량을 늘리는 선택**이다. 2D 전환의 목적이 "저비용·시간 절약"이므로 에셋 총량이 목표와 어긋날 수 있다. 완화안(결정 아님, 필요 시 사용자가 선택): ① 이동·공격 입력은 8방향이어도 스프라이트는 4방향(+좌우 미러)으로 표시, ② 프레임 수·디테일 상한, ③ P0 화풍 실험에서 32px·8방향의 실제 제작 시간을 측정해 16px/4방향으로 되돌릴지 판단한다. 최종 값은 측정 후 조정한다 **[측정]**.

### 4.2 지형 변형의 2D 표현 (독자 요소, 결정 1·21·98·99)
| 안 | 설명 | 장점 | 위험 |
|---|---|---|---|
| A 타일 상태 전환 | 땅 타일이 평지 ↔ 구덩이(깎음) ↔ 돋운 땅(쌓음)으로 단계 전환(예: 구덩이 −2~0, 돋움 0~+2 **[가정]**) | 가장 단순. 델타 저장이 타일 변경 목록. 마소 농도 → 최대 단계(한계) | "땅이 높아진다"의 시각이 약할 수 있음 |
| B 층(높이 단계) 레이어 | 타일마다 높이 값, 높이 차에 따라 절벽·경사 타일 | 젤다식 단차·오르내리기 표현 가능 | 시각 규칙·충돌 규칙이 복잡 |
| C 벽/바닥 타일 쌓기·파내기 | 코어 키퍼식으로 땅을 파면 길이 되고, 쌓으면 벽·언덕이 됨 | 단순, 검증된 방식 | 높낮이 감각이 약함, 다리·경사 표현이 어색할 수 있음 |
- 공통: 마소 농도 → **최대 단계(한계)**(결정 98), 건축물 아래 **기초 보호 타일 마스크**(결정 99), 지도는 원본 기준(결정 71, 변형 미반영), 델타 저장은 변경된 타일 목록만.
- 대형 함정·함몰(결정 74): 구덩이 타일에 대형이 진입하면 빠지는 상태, 무방비 시간 [측정].
- 미오 서브스토리 2단계(끊긴 길에 지형 쌓기): 구덩이/절벽을 돋운 땅 타일로 메워 건너는 메카닉.
- 물 규칙(결정 20): 타일 물 높이 규칙이 3D 격자 규칙보다 단순해진다 [제안].
- **확정(결정 115): 빌더즈식 블록 높이(B의 단순화).** 드래곤 퀘스트 빌더즈의 3D 블록 쌓기·부수기 감각을 2D 탑다운에서 재현한다. 이전 추천(A 또는 C)은 대체됨.
  - **높이 값:** 타일마다 정수 높이 값(블록 개수). 쌓기 = +1, 깎기 = −1. 마소 농도가 최대 높이·최대 깊이 한계를 정한다(결정 98). 초기값 예: 시가지 +1/−1, 경계지 +3/−2, 요정숲 +4/−3 **[가정, 측정]**.
  - **절벽 타일:** 이웃 타일과 높이 차가 있으면 그 경계에 절벽(또는 경사) 타일을 보여 준다. 오토타일 규칙으로 조합한다.
  - **이동 규칙 [제안]:** 높이 차 1은 오를 수 있다(계단 효과). 높이 차 2 이상은 막힌다. 블록을 쌓아 계단·다리를 만들고, 깎아 구덩이를 만든다. 구덩이(높이 −1 이하)는 대형이 진입하면 빠지는 판정(결정 74)과 연결한다.
  - **미오 서브스토리 2단계(끊긴 길):** 끊긴 구간이 높이 차 2 이상 구덩이/절벽이며, 쌓아서 높이 차를 1 이하로 만들어 건넌다. 3단계(건너편 조사)도 높이 쌓기·깎기로 접근.
  - **건축물:** 바닥 면 + 여유 1칸은 변형 불가(결정 99, 타일 마스크). 건축물은 평지(높이 0)에서만 지을 수 있다 [제안].
  - **저장:** 변경된 타일의 (좌표, 높이 값) 목록만 델타로 저장한다(결정 71과 분리). 원본 타일 맵은 읽기 전용.
  - **지도:** 원본 지형 기준(결정 71). 변형 높이를 반영하지 않는다.
  - **비용·위험 [제안]:** 절벽 타일 아트(방향별 조합)와 높이 충돌 규칙이 A보다 일이 많다. 탑다운에서 높이를 시각으로 전달하려면 절벽의 면 처리가 필요하다. 프로토타입에서 시각 가독성과 이동 규칙의 재미를 먼저 검증한다. 불합격이면 A(상태 전환)로 후퇴한다.


### 4.3 기타 2D 설계
- **젤다 기법 2D 변형:** Z 3.2(신들의 트라이포스, 2D 탑다운)·Z 3.11의 규칙 중 눈높이 시야 의존 부분(삼각형 규칙의 시선 유도)은 **지형 형태·가림·랜드마크 위치**로 대체한다. 랜드마크(녹슨 철골)는 화면 위로 솟아 보이는 실루엣으로 표현 [제안].
- **던전의 "아래":** 지하 이동은 별도 맵(층)으로 표현한다. 입구는 낙반 타일(결정 84)로 막힘.
- **스트리밍:** 타일 청크 로딩. 월드 크기(중간)가 2D에서도 중요한 변수인지는 프로토타입으로 측정 [측정].
- **전투:** 탑다운 8방향(또는 4방향) 근접·원거리 가벼운 액션. 락온 불필요. 낮은 난이도 옵션 유지(수칙 1).
- **카메라:** 플레이어 추적 스크롤, 화면 흔들림 연출. 별도 충돌 처리 불필요.

## 5. 프로토타입 D 개정 방향 **[제안]**
`prototype-d-spec.md`(3D 기준)는 **보류**한다. 2D 개정판의 뼈대:
- **질문 개정:** Q1 입력 지연(타일 변경 반영), Q2 델타 저장(타일 변경 목록 용량·시간), Q3 타일 청크 경계 일관성, Q5 마소 농도 단계 한계의 체감, Q6 건축물 기초 보호 마스크, Q7 구덩이 함정·함몰 대형 샘플, Q9 1인 구현 복잡도. **삭제:** Q4(3D 충돌), Q8(3D 카메라).
- **방식 후보:** §4.2의 A·C(필요 시 B). 합격선(결정 97의 가정값 그대로 시작): 프레임타임·히치·저장·불러오기·입력 지연. 2D는 더 쉬워질 것으로 **추정**한다.
- **새 항목:** 타일 단계 시각 구분(픽셀 아트로 높이 느낌이 전달되는가), 스프라이트 애니메이션 프레임 상한 측정.
- **퇴로:** 변형 범위를 지정 구역으로 축소 → 독자 요소 재검토(기존과 동일).

## 6. 엔진 재평가 방향 **[제안] — 완료: `engine-comparison-memo-2d.md`**
- 이전 순위는 3D 지형 변형(Voxel Tools) 근거 → **무효.** 2D 타일 기준으로 후보를 다시 비교한다. 후보: Godot, Unity, 그 외 2D 전용 도구(예: GameMaker 등, **이번 조사 없음**).
- 재사용 가능한 이전 조사: 라이선스 정보(Godot MIT 미러 확인, Unity Personal 20만 달러 기준 요약, Unreal 로열티), Steam 등록비 100달러, 발헤임=Unity(3D 사례라 참고만).
- 2D에서 새로 확인할 것: 타일맵 시스템의 런타임 편집 API, 타일 청크 스트리밍 사례(코어 키퍼 엔진 등 미확인), 픽셀 퍼펙트 렌더링 지원, Steam 배포.
- 엔진 게이트 개정: **완료**(`engine-gate-plan.md` 2D 개정판): 타일 청크 월드(1024×1024 타일 [가정]), 지형 변형 시나리오 T1~T8, 픽셀 퍼펙트·오토타일 측정. 합격선·마진 규칙(결정 96~97)·엔진당 2주 상한(결정 100)·가중치(결정 101)는 그대로 쓴다.
