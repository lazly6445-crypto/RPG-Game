# 핵앤슬래시 전환 방향 (결정 133, 초안)

> 상태: 방향 결정만 됨. 아래는 현재 구조에 대한 영향 정리와 **미결정 질문**이다. 수치·구현은 사용자 확인 후.

## 1. 결정된 것
- 가져갈 요소: **다수의 적을 베는 쾌감 / 드롭·장비 파밍 / 스킬·콤보 확장**.
- 가져가지 않는 것: 빠른 템포·낮은 처벌 — 회피 중심 정밀 전투(선딜-판정-후딜, 무적 구간, 입력 버퍼)는 유지.
- 난이도 수치 조정(보통 등)은 이 설계 이후로 미룬다.

## 2. 현재 구조와의 접점 (코드·데이터 확인된 범위)
| 요소 | 현재 | 전환 시 건드릴 곳(예상) |
|---|---|---|
| 다수 적 | 몬스터 수 ×1.8/2.6, 개체 체력 ×1.5/2.0(난이도), 소굴당 상한 8, 던전 구간 상한 12 (`difficulty.json`) | 개체 약화 + 수 증가, 광역/관통 판정(CombatSim 판정 모양에 다수 타격·관통 추가) |
| 공격 | 단일 근접 1타, 부채꼴/사각형 판정, 히트스톱 (`combat.json`) | 콤보 단계(1·2·3타), 광역 스킬, 처치 연출 |
| 드롭 | 재료 드롭 `loot.json`, 개수 배율 | 장비 드롭(등급·옵션), 장비 슬롯, 인벤토리·제작 UI 확장(B22 화면 재사용) |
| 스킬 | 없음(공격·회피만) | 스킬 슬롯, 쿨다운/마나 소비(마소 시스템과 연결 가능), 해금(unlocks) |
| 저장 | 인벤토리·진행·지형 delta | 장비·스킬 상태 저장(포맷 확장 필요) |

## 3. 미결정 질문 (하나씩 결정)
1. ~~장비 구조~~ → **결정 134:** 슬롯 5개 이상(무기·머리·몸·장갑·신발·장신구 등, 목록은 설계 시 확정), 등급 4단계(일반/희귀/영웅/전설), 무작위 옵션.
2. ~~스킬 구조~~ → **결정 135:** 슬롯 4개, 자원 쿨다운+마소 모두, 획득은 드롭(스킬 북).
3. ~~경험치·레벨~~ → **결정 136:** 레벨 도입.
4. ~~생존·자원 압박~~ → **결정 136:** 핵슬 루프 우선, 자원은 드롭 재료로 통합(결정 129의 생존 압박 상향은 대체).
5. **기존 요소와의 관계:** 지형 변형(고저차)을 전투에 살리는 방식 유지(규칙 시스템: 불·물), 마소 규칙의 몬스터 강화.
6. **보스(문지기)의 위치:** 핵앤슬래시의 최종 관문으로 유지?
7. 기존 난이도 3단계(쉬움/보통/어려움)와 [가정] 수치의 처리: 전환 후 재설계.

## 4. 진행 방식 제안
질문 1~7을 하나씩 결정 → `gdd-1.0.md` 해당 절과 결정 번호 반영 → 구현 항목(B28~)으로 분해(전투 확장 → 장비·드롭 → 스킬 → UI → 저장 확장 → 밸런스 재조정).
