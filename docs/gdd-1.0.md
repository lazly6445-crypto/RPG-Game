## 2. 절대수칙 4개 [확정]

1. **난이도가 너무 어려워서는 안 된다.** 조작·전투·진행에만 걸린다. 이야기의 무게에는 걸리지 않는다. → 낮은 난이도 옵션은 필수 기능.
2. **메인스토리에서 벗어나도 즐거워야 한다.** 진행 잠금을 두지 않는다. 단, 이동기/도구 해금은 허용한다(월드 탐험의 보상으로 얻는다).
3. **저장·불러오기가 자유롭다.** 어디서나 저장한다. 되돌려 다시 해도 결과는 같고 게임은 막지도 사과하지도 않는다.
4. **모든 걸 설명하지 않는다.** 조작법 안내는 예외.

## 3. 설계 기둥

1. **곱셈형 규칙** [제안]: 소수의 일관된 규칙(마소·물·불)을 지형 변형과 곱한다. 퍼즐마다 전용 오브젝트를 만들지 않고 규칙으로 푼다(Z 2장, Z 3.11).
2. **밀도 > 크기** [제안]: 작고 조밀한 월드(R 4.4).
3. **환경이 안내한다** [제안]: 삼각형 지형, 랜드마크, 마커 최소(Z 3.11).
4. **저폴리곤을 제약이자 정체성으로** [제안]: 제작 회전이 빠르고 저사양에서 돈다(R B.6). 조명·색·카메라·사운드에 예산을 배분해 "싸 보임"을 피한다.
5. **독자 요소 1개** [확정]: 지형 변형 도구. 젤다류는 구조만 닮으면 "복제" 평가를 받는다(ZL 7장).

## 4. 세계관

### 4.1 「겹침」
- 어느 날 밤 두 세계(현대 / 마법 판타지)가 **충돌이 아니라 겹쳤다.** 며칠에 걸쳐 일어났고, 방송이 끊긴 건 그다음이다.
- 공식 명칭은 없고 사람들이 「겹침」이라 부른다. 인류 대부분이 적대적인 존재에게 공격당해 문명이 무너졌다.
- **왜 일어났는지는 결말 전까지 게임 안에서 답하지 않는다.** (§10)

### 4.2 섞이는 세 방식 (설명하지 않는다)
| 방식 | 모습 | 성격 |
|---|---|---|
| 덧씌움 | 아파트 단지가 선 채 숲이 됨 | 사람이 살던 흔적이 많아 파밍이 가장 잘 됨 → 요정숲 |
| 잘라냄 | 한 구역이 통째로 사라지고 다른 세계 땅이 들어앉음. 경계가 칼로 자른 듯 선명 | 두 세계가 맞닿은 선 → 경계지 |
| 마경 | 어느 세계도 아닌 곳, 물리 법칙이 어긋남 | 출시 후 후보(1.0 제외) |

던전은 겹침이 남긴 구멍이다. 지하철 입구·지하주차장 등 아래로 내려가는 곳이 입구가 된 경우가 많다. 왜 하필 그런 곳인지는 설명하지 않는다.

### 4.3 마소(魔素)
- 마소는 마력 그 자체다. **지역마다 농도가 다르다**: 시가지(옅음) < 경계지 < 요정숲(짙음). 던전은 **깊어질수록 짙어진다**: 입구는 시가지 수준 → 심부는 요정숲 수준 [확정], 구간별 값은 **[측정]**.
- **몸에 쌓여 강해지는 것은 판타지 세계의 주민과 주인공뿐이다.** 일반 사람(현대 생존자)은 옅은 곳에서는 소량의 마법을 쓸 수 있지만 짙은 곳에서는 건강이 나빠진다. 해는 사람마다 다르고 언제 나빠질지 모른다(각본, 시뮬레이션 아님).
- 게임 안에서는 "겹침 이후 누구나 조금씩 마법을 쓸 수 있게 됐다, 재능이 아니라 환경이 바뀐 것"이라고 말한다. 옅은 곳에서는 맞고 짙은 곳에서는 위험하며, 주인공에게는 거짓이다(§10).
- 일반 사람에게 마소가 해롭다는 사실은 **단서만 쌓고 설명하지 않는다**(미오의 쇠약, 생존자들이 시가지를 떠나지 않는 것, 기록의 조각). 플레이어 자신은 짙은 곳에서도 멀쩡하며, 이 차이가 복선이다.
- 플레이어의 마소는 몸에 쌓은 양 기준이며 지역 농도에 영향받지 않는다. 마력석 등은 플레이어의 발광과 밝힘만 담당하고 지역 농도를 바꾸지 않는다.
- 구현된 규칙(2D 시절 [구현]): 마력석을 집으면 마소가 쌓임 → 3 이상이면 몸이 스스로 빛나 발밑을 밝힘 → 마력석 등(마력석 1 + 고철 2)을 세울 수 있음.

### 4.4 몬스터와 적대적인 존재
| 부류 | 성격 |
|---|---|
| **몬스터** | 판타지 세계에서 넘어온 것들. **악의 없음** — 배고프거나 영역을 지키거나 원래 그렇다. 대부분 피할 수 있다. 능력치는 지역 마소 농도에 비례해 연속적으로 변한다 |
| **적대적인 존재** | 사람을 **골라서** 노린다. 이유는 모른다. **던전에만 등장한다**(1.0) |
| **살아남은 사람들** | 대부분 무섭고 지쳐 있다. 「인간 = 적」으로 고정하지 않는다 |

## 5. 주인공

- 이름·직업은 정하지 않는다(플레이어가 채울 자리). 플레이어가 바꿀 수 없는 고정 사실: **가족을 두 번 잃었다.**
- 겹침 이전에 사고로 가족을 잃은 고아였고, 다시 가정을 이뤄 반려자와 아이가 있었으며, 겹침이 그것을 두 번째로 빼앗았다. 세계를 구하려는 것이 아니라 **되찾으려는** 것이다.
- **두 번의 인생(오해 금지):** 첫 인생은 판타지 세계, 두 번째 인생이 현대세계다. 잃은 가족은 전부 두 번째 인생(현대세계)의 가족이다.
- "평범해 보이지만 평범하지 않다." (이전 초안의 「특별하지 않다」는 폐기)
- 플레이어 캐릭터는 마소를 몸에 쌓아 강해지고, 짙은 마소 지역에서도 이상이 없다(§4.3).

## 6. 월드

### 6.1 지역 (1.0)
| 지역 | 겹친 방식 | 성격 | 마소 | 몬스터 |
|---|---|---|---|---|
| 튜토리얼 통로 | — | 두 언덕 사이 골짜기. 끝까지 걸으면 시가지로 이어진다. 글·팝업 없이 길 위의 잔해 6개로 걷기와 줍기를 겪게 한다. 처음 걸어 나오는 순간 말없이 한 번 자동 저장 | — | 없음 |
| 무너진 시가지 | 원래 세계 | 시작 지역. 마법 자원 거의 없음, 현대 잔해. 실내에 들어갈 수 있는 건물(안이 벌판보다 자원이 풍부), 도로·골목, 멀리서 알아보는 랜드마크(녹슨 철골)가 **회복 장소**(체력은 여기서만 참) | 옅음 | 들개(호칭) |
| 경계지 | 잘라냄의 경계선 | 다른 세계의 땅이 네모나게(한 변 5~11칸) 들어앉은 「잘라낸 자리」, 보라·청록 땅빛, 마력석이 시가지보다 짙음 | 중간~짙음 | 불나비 |
| 요정숲 | 덧씌움 | 건물이 선 채 나무·수풀이 복도 안까지 자람. 채집 밀도가 다른 두 지역보다 뚜렷이 높다(경계지의 2.6배, 글로 적지 않음). 맵의 약 16% | 짙음 | 가시뿌리 |
| 던전 1개 | 겹침의 구멍 | 지하로 내려가는 곳. 회귀 실마리(던전 깊은 곳의 기록)가 있다. 입구는 낙반으로 막혀 있어 **경계지에서 얻는 설계도로 만든 도구**가 있어야 열린다 [확정] | 입구 옅음 → 심부 짙음 | 적대적인 존재 3종 + 대형 1종 |

출시 후 후보: **드워프 지하마을**(광물·제작 설비, 대장간이 아직 뜨겁다, 주인이 어디 갔는지는 모른다), **마경**.
컨셉상 "칸" 단위였던 치수(튜토리얼 100칸×9칸 등)는 3D에서 미터로 재정의한다 **[측정]**.

### 6.1a 월드 크기 [확정: 방향만]
**중간** — 지역 간 이동에 수 분, 넓은 탐험 공간. 숫자(km², 지역별 치수)는 근거가 없어 P1 측정치로 확정한다. 기둥 2(밀도 > 크기), 1인·파트타임·외주 없음 전제와 **긴장 관계**다: 중간 크기는 지형 제작량·스트리밍·지형 변형 저장 크기·빈 구간 위험을 키운다. 일정 단축 방안의 첫 후보는 "월드 크기 축소"다. 완화: 수직성과 삼각형 규칙으로 체감 크기를 만들고, 4지역을 이웃하게 배치해 이동을 짧게, POI 클러스터를 먼저 배치하고 사이를 채운다.

### 6.2 월드 설계 규칙 [제안]
- **수작업 큰 틀 + 도구 보조 산포.** 핵심 지점(보스, 마을, 던전 입구, 대형 랜드마크)을 먼저 배치하고 지형을 맞춘다(엘든 링식, R 4.5). 삼각형 지형으로 시선을 유도한다(Z 3.11).
- 자원·적·보상은 **미니 클러스터**로 묶는다. 어디서나 성격이 다른 POI가 지평선에 3개 이상 보이게(R 4.2, C라 검증 필요). POI 이동 간격 60~120초는 단일 블로그 경험칙이라 **[측정]** 필수.
- 소형 랜드마크도 멀리서 읽혀야 한다. 저폴리곤이라 실루엣과 색으로 구분한다.
- 새 지역은 시각만이 아니라 위협·자원·환경 규칙이 달라야 한다(R 18.3 Luban 2부).
- 이동 차단은 임의 장벽이 아니라 게임플레이 조건으로. 건너뛰는 구역은 플레이테스트로 찾아 은은한 표지를 더한다.
- 레벨 스케일링은 쓰지 않는다. 지역마다 고정 위험도를 둔다(R 9.1).

## 7. 핵심 시스템

### 7.1 코어 루프
```
줍는다(파밍) → 쌓인다 → 짓는다(건축) / 땅을 쌓고 깎는다(지형 변형)
        ↑                                   ↓
   탐험(이동기 해금)  ←  규칙 조합으로 길을 연다  ← 서브스토리·회귀 실마리
```
| 시간대 | 질문 | 장치 |
|---|---|---|
| 몇 초 | 한 번의 조작이 즐거운가 | 이동·회피·줍기, 히트스톱 |
| 몇 분 | 눈에 띈 것을 향해 가는 동기가 있는가 | 랜드마크 유도, 삼각형 지형 |
| 한 시간 | 한 번의 모험이 완결감이 있는가 | 퀘스트, 던전 |
| 10시간 | 성장과 새 가능성이 열리는가 | 이동기·도구 해금, 숙련도 |
| 50시간+ | 새 목표·관계가 생기는가 | 인연·서브스토리, 출시 후 확장 |

### 7.2 지형 변형 (독자 요소)
- 플레이어가 땅을 **쌓고 깎는다.** 방식은 P0 프로토타입 D에서 실측해 결정한다: 높이맵 편집(단순, 동굴·오버행 불가), 복셀/청크(자유도 높음, 비용 큼), 격자 블록(저폴리와 궁합 좋음, 구현 쉬움). **[제안, 미검증]**
- **저장은 델타만:** 원본 지형은 읽기 전용, 변형 차이만 세이브에 저장한다 [제안].
- **마소 농도가 변형 범위·내구를 정한다** [확정]: 옅은 시가지는 작게·쉽게 무너지고, 짙은 경계지·요정숲은 크게·오래 유지된다. 지형 변형 × 마소가 이 게임의 독자 조합이며 프로토타입 D에서 가장 먼저 검증한다.
- 건물 아래 지형을 깎으면 어떻게 되는가, 변형 불가 영역을 어떻게 표시하는가는 건축과의 상호작용으로 **함께 검증한다** [제안].
- 비용이 감당 안 되면 변형 범위를 축소한다: 전 지형 자유 → 격자 블록 단위 → 지정 구역만 [제안].
- **지도는 변형 결과를 반영하지 않는다.** 지도는 원본 지형 기준이다 [확정].

### 7.3 곱셈형 규칙: 마소 · 물 · 불
| | 지형 변형 | 마소 | 물 | 불 |
|---|---|---|---|---|
| **지형 변형** | — | 농도가 변형 범위·내구를 결정 [확정] | 판 땅이 물길을 바꿈. 파면 물이 고이고, 쌓으면 막힘 | 불의 번짐을 지형으로 끊음(방화선) |
| **마소** | | — | 후보(미확정): 마소 짙은 물이 빛남/약효 | 후보(미확정): 마소 짙은 곳에서 불이 더 강하거나 오래감 |
| **물** | | | — | 물이 불을 끔. 젖은 연료는 불이 안 붙음 |
| **불** | | | | — |
- 규칙 수는 3개(+ 지형 변형)로 상한 [확정]. 무게/중력은 제외.
- 규칙은 **데이터 표**(속성 태그 + 상태 + 자극 → 결과)로 정의한다. 조합 매트릭스는 문서로 관리하고 칸마다 의도한 결과 또는 "정의 안 함"을 적는다(TotK 방식, Z 3.12). 자동 시뮬레이션 테스트를 둔다.
- 물은 구현 비용이 가장 크다. 유체 시뮬레이션이 아니라 **격자 위 물 높이/흐름 규칙**으로 제한한다 [제안]. 물 × 지형 변형이 감당 안 되면 물을 빼고 마소·불 2개로 줄인다(P0 종료 게이트에 명시).

### 7.4 건축·제작·채집 [구현 설계를 3D로 이식]
- **기본 재료 6종(현대 잔해):** 판자 · 고철 · 천 조각 · 유리 조각 · 전선 · 플라스틱. 어느 지역에서도 여섯 모두 나온다(지역 전용 잠금 재료 없음). **판타지 재료:** 마력석.
- **건축:** 판자 바닥 · 판자벽 · 판자문. 설치물 충돌, 실내 판정(문 포함 벽으로 둘러싼 칸), 부수기(조리법 절반 환급).
- **도구:** 쇠지렛대(자판기 개봉·채집 보너스), 쇠파이프(근접 무기), 붕대(즉시 체력 40), 덧댄 외투(개 한 입을 절반으로), 마력석 등.
- **채집 숙련도:** 레벨 1~5, 컨테이너·자판기에서 더 많이 나옴(잠금 없음, 보상일 뿐). 바닥 잔해는 일부러 희소(건물 안의 10분의 1), 건물 방마다 나무 상자·철제 사물함이 뒤지는 맛을 준다.
- 실내는 **반투명/커트어웨이**로 보여준다: 실내에 들어가면 지붕과 시야를 가리는 벽이 페이드아웃한다 [확정].

### 7.5 전투
- **가벼운 액션.** 싸울지 피할지는 플레이어가 고른다. 엘든 링식 자세 게이지·스태미나 전투는 도입하지 않는다 [제안] (P0 프로토타입 A에서 둘 중 필요 여부 최종 확인).
- 입력 버퍼, 히트스톱, 카메라 흔들림, 피격 반응, 적 예비동작 가독성이 필수 [제안]. **무기 내구도 없음** [확정].
- 성공 기준: 숙달 없이도 이긴다. 처음 해보는 테스터 5명 중 4명이 설명 없이 회피·공격·주목을 사용한다 **[가정]**.
- 능력치 수치는 데이터 테이블에 둔다 **[측정]**. 낮은 난이도 옵션은 체력·공격력 배율을 낮추고 지형 변형 공략의 효과를 키운다 [제안].

### 7.6 성장·죽음·이동기
- 성장 축은 **능력 해금(이동기·도구) + 소량의 수치(채집 숙련도, 마소)** 이다 [제안]. 스킬 트리를 쓰면 노드가 새 선택지를 열어야 하며 +% 필러는 피한다(R 17.4).
- **이동기·도구 해금 허용** [확정]: 월드 탐험의 보상으로 얻고, 메인 스토리 진행 없이도 얻을 수 있다. 강한 이동 도구가 탐험 동기를 깎지 않게 해금 시점·비용을 설계한다(Z 7장).
- **죽음은 벌이 아니라 "아 아까웠다":** 체력 0 → 쓰러짐 → 가장 가까운 가 본 회복 장소에서 깨어남, 기본 재료 절반만 잃음(장비·도구·설치물·숙련도는 안 잃음).
- **던전에서는 다르다:** 적대적인 존재는 일반 몹처럼 데미지를 주고받아 처치할 수 있고, 플레이어 체력이 0이 되면 **던전 입구(밖)로 되돌려진다. 재료 손실 없음.** 던전 진행 상태(열린 문, 가져온 기록)는 유지한다.
- 경제: 시작 전에 수입 총량 대비 예상 지출을 계산하고 실제 플레이로 비교한다 [제안]. 유료 랜덤 요소(확률형)는 두지 않는다.

### 7.7 카메라·UI·지도·접근성
- **3인칭 추격 카메라** [확정]. 지형·건축물 충돌, 지형 변형 직후 위치 보정, 좁은 실내, 주목(락온)을 P0 프로토타입에서 함께 검증한다. 비용이 과도하면 **쿼터뷰 3D(고정각)로 후퇴**하며 후퇴는 사용자 승인 후에만 한다.
- 지도: 기본은 **마커 최소.** 가이드 모드 옵션으로 마커 밀도를 올린다. 지도는 원본 지형 기준, 안개로 탐험 기록을 남긴다. 나침반은 추적 퀘스트와 웨이포인트는 항상, 그 외는 반경 내에서만 [제안].
- **인연 수치·게이지·경고를 어떤 UI에도 표시하지 않는다.** 관계 진전은 말투·방문·건네는 것 같은 허구 안의 신호로만 드러난다.
- 온보딩: 튜토리얼 통로 방식. 첫 10분 안에 이동·줍기·전투 또는 규칙 상호작용 1개를 겪게 하되 안내는 스킵 가능.
- 접근성: 키 리매핑, 자막 크기, 색약 대응, 난이도 옵션을 슬라이스에서 구현(처음부터 계획해야 가능, R 11.3).

## 9. 사람들과 서브스토리

### 9.1 평범한 생존자 두 명 (시가지) [구현 설계]
| | 노인 | 낯선 사람 |
|---|---|---|
| 첫마디 | 「살아 있는 사람은 오랜만이군.」 | 「가까이 오지 마.」 |
| 결 | 길고 담담함 | 짧게 끊김 |
| 대표 대사 | 「뉴스에서 그걸 다루는 동안에는, 아직 세상이 굴러간다고 믿었지.」 | 「…아직 그런 소리를 하는 사람이 남아 있군. 천 조각. 밤에 바람이 들어온다.」 |
- 낯선 사람의 첫 부탁(천 조각 3개 → 고철 4 + 전선 2)은 수락/거절 창 없이 "묻는 것이 곧 받는 것"이다. 이 방식이 모든 열쇠 부탁의 기본형이다.
- 둘은 평범한 생존자이며 여주인공 포지션이 아니다. 마소가 옅은 시가지에 머무는 이유가 §4.3으로 설명된다.

### 9.2 인연 시스템 — 「엮이면 불행해진다」 [확정]
1. 인연이 쌓이면 서브스토리가 열린다. 서브스토리는 퀘스트 형태로 진행된다.
2. 완료하면 **불행한 결말**이 오고 서브스토리 1개당 결말 1개, 분기하지 않는다.
3. 여주인공 포지션 NPC **2명**이 있고 전원 죽음을 맞는다.
- 인연 수치는 플레이어에게 숨긴다. 저장 키 이름은 `ties`. 수치 규칙: 화제를 처음 들으면 +1, 부탁을 끝내면 +3. 서브스토리는 **임계값 5(열쇠 부탁 +3 + 화제 2개)** 에서 열린다. 화제 수는 인물당 4개 [확정].
- 서브스토리 경고를 주지 않는다(확인창·위험 아이콘·암시 색상 없음). 첫 번째는 뒤통수고 그건 의도다.
- 죽는 NPC는 대체 불가능한 기능에 묶지 않는다. 피하는 플레이는 유효하지만 유리하지 않다(진행하면 콘텐츠는 순증).
- **인물당 퀘스트 4개**: 열쇠 부탁(서브스토리 이전) 1 + 서브스토리 3단계. 두 인물 합계 8개.
- 비극은 3단계 완료 후 **다음 방문 때 부재를 발견**하는 방식이다. 컷신·알림 없음.

### 9.3 여주인공 포지션 NPC 두 명 [확정] — ⚠️ 스포일러 포함 설계 메모

| 3단계 | 문을 열어 두고 불 밝히기(마력석 등) | 건너편 조사 동행. 지형을 파거나 쌓아 접근. 미오가 어렴풋이 눈치채는 장면 1회 |
| 보상 | 붕대 강화 레시피 → **체육관을 회복 장소로 등록**(비극 이후에도 유지) → 에닐의 가방(의료 재료·상위 붕대 레시피) | 경계 표지 위치가 지도에 표시 → **지형 변형 범위 소폭 확장** → 비극 이후 **미완성 지도를 이어받아** 경계지 일부 해금 |
| 신호 | — (우연 사고이므로 없음) | **대사 하나뿐**: 숫자와 방향을 정확히 되뇌는 말투가 단계마다 짧아지고 같은 말을 반복한다. 강도 곡선은 거의 없음 → 눈에 띔 → 분명함 |
| 비극 이후 | 대피소 문은 안 잠긴 채. 소지품과 무너진 건물 자리 | 거처·작업 장소에 미완성 지도가 놓여 있다. 대사 없음 |

- 에닐은 사람들을 모으려 했던 인물이고, 대피소는 에닐이 남긴 흔적으로 계속 쓰인다(기록 1번 「문은 안 잠갔습니다. 돌아오면 그때 잠그겠습니다.」과 같은 톤).
- 미오의 목표는 완성되지 않는다. 건너편에 무엇이 있는지는 게임이 답하지 않는다.
- 미오의 초안 대사(톤 확인용, 확정 아님): 1단계 「북서로 사십이 보. 표지가 둘, 여기가 첫째.」 → 2단계 「북서로 사십이. …사십이 보. 표지가 둘.」 → 3단계 「사십이. 사십이. …다음 표지가 어디였지.」
- 미오의 신호 채널이 대사뿐이라 놓치는 플레이어가 있을 수 있다. 플레이테스트에서 "언제 알았는가"를 측정하고, 너무 놓치면 지도 필체 흔들림을 추가한다 [제안].
- 서브스토리 보상 연출은 최소화한다(축하하는 톤 금지). 미오 보상이 더 강하므로 서브스토리를 피한 플레이어도 기본 범위로 필수 진행이 가능해야 한다.

### 9.4 요정 NPC
- 판타지 세계 주민이며 여주인공 포지션이 아니다. 마소에 영향을 받지 않고, **시가지에 오지 않는다.** 요정숲에서 만난다.
- 말투: **시큰둥하고 돌려 말한다**(대답이 한 단 비틀려 있음), **반말.** 노인(길고 담담)·낯선 사람(짧게 끊김)과 구분된다.
- 초안 대사(톤 확인용): 첫 만남 「또 하나 걸어 들어왔네. 신발이나 닦아.」/ 길을 물으면 「길은 숲이 정해. 나한테 물을 일은 아니고.」
- **주인공을 알아보는 듯한 반응을 아주 은근히 넣는다**: 한 번 오래 바라본 뒤 「…아니, 아무것도.」 같은 정도. 한 NPC가 연달아 반복하지 않고, 이전 만남·이름·과거를 암시하는 단어를 쓰지 않는다.
- 요정이 회귀 실마리(판타지 주민이 아는 것)의 한 갈래를 맡는다(대사에 살짝).

### 9.5 흩어진 기록 8장 [구현 설계]
겹침 직후 사람들이 남긴 메모·낙서. 시가지(짝수 번)와 경계지(홀수 번)에 흩어져 있고 다가가서 읽는다. 순서·필수 없음, 읽은 장은 화면에서 바래진다. **어느 한 장도 답을 주지 않고 조각만 준다.**
1. 문에 붙은 쪽지 — 「3동 사람들은 학교 체육관으로 갑니다… 문은 안 잠갔습니다. 돌아오면 그때 잠그겠습니다.」(에닐)
2. 표지판에 긁어 쓴 글 — 길이 끊긴 곳, 「건너갈 생각 하지 마라. 돌아가라.」(미오)
3. 셔터에 분필로 쓴 글 — 「문 닫습니다… 돈은 안 받습니다.」/(다른 손글씨로)「세 번 왔습니다. 고맙습니다.」
4. 찢어진 수첩 한 장 — 경계 너머에서 온 사람을 만남. 「되돌리는 법을 아는 이들이 있었다고 했다. 있었다고, 지난 일처럼 말했다.」(미오)
5. 벽에 적힌 날짜 — 「첫째 날, 아직 방송이 나온다. 넷째 날, 안 나온다. 열흘째. 세는 걸 그만둔다.」
6. 돌에 눌린 편지 — 「이걸 읽는 사람은 나보다 멀리 온 사람이다. 물은 아껴 마셔라.」
7. 전단지 뒷면 — 「전부 되돌릴 수 있다는 말이 돈다… 그러면 그날 뒤에 만난 사람들은 어떻게 되나. 나는 그 뒤에 아이 하나를 주웠다.」
8. 판자에 새긴 글 — 잘라낸 자리의 불나비를 경고하는 글

기록 문구에 마소가 일반 사람에게 해롭다는 사실을 직접 적지 않는다.

### 9.6a 메인 스토리 구조 [확정]
**실마리 수집형:** 회귀 실마리 조각을 일정량 모으면 마지막 에피소드가 열린다. 모으는 순서는 자유이며 별도의 선형 메인 퀘스트 줄은 만들지 않는다. **던전은 이동기/도구 해금 후에 열린다.** 해금 도구는 서브스토리와 무관하다 [확정]: 던전 입구는 **낙반(무너진 잔해)으로 막혀 있고**, **경계지 POI에서 얻는 설계도(레시피)로 낙반을 치우는 도구(가칭 "굴착 도구")를 직접 제작**한다. 같은 도구가 시가지의 낙반 샛길·지름길에도 쓰이게 하는 안이 있다 [제안]. 정식 이름·재료·획득 POI 위치는 미정. "일정량"에는 **던전 기록(첫째 갈래)이 필수 조각**으로 포함된다 [확정]. 나머지 두 갈래(요정, 흩어진 기록)는 수집량을 채우는 자유 조각이다. **조각은 총 14개(흩어진 기록 8 + 요정 대사 4 + 던전 기록 2, 던전 기록 중 1개는 필수), 마지막 에피소드가 열리는 일정량은 약 60%인 8개** [확정]. 최단 경로는 던전 필수 1 + 흩어진 기록 7이므로 요정숲을 안 가도 마지막 에피소드가 열린다 — 요정 복선을 못 본 플레이어를 위해 다른 복선 후보를 병행한다. 수집 상태는 UI에 표시하지 않는다.

**마지막 에피소드의 신호와 시작 [확정]:** 조각이 8개가 된 뒤 처음으로 회복 장소에서 쉬면 **짧은 장면(꿈)** 이 한 번 나오고 **월드 한 곳이 변한다.** 수치·게이지·알림은 없다. 마지막 에피소드는 **시가지의 랜드마크(녹슨 철골)에서 시작**한다 — 시작 지역으로 돌아온다. 열렸다고 강제 진행되지 않고 플레이어는 계속 탐험할 수 있다. 장면 내용과 변화 지점 연출은 미정(기억의 구멍 복선과 연결, 반전을 직접 말하지 않음).

### 9.6 회귀의 실마리 (1.0은 3갈래)
1. 던전 깊은 곳의 기록 2. 판타지 세계 주민이 아는 것(요정 대사) 3. 흩어진 기록(§9.5)
(4번째 갈래인 마경은 출시 후 후보.) 실마리는 한 줄로 주어지지 않고 세계 곳곳에 흩어져 있다. **되돌리는 게 옳은지 자체가 명확하지 않고, 게임은 답하지 않는다.** 결말 분기에 필요한 정보가 3갈래로 충분한지 스토리 확정 때 점검한다.

## 10. ⚠️ 결말 반전 (스포일러)

**주인공이 겹침의 원인이다.** 기억을 잃은 **판타지 세계의 회귀자**. 원래는 현대세계 사람이 아니라 판타지 세계의 영혼이 현대세계에서 살고 있었고, 그래서 **주인공과 엮이는 인연들에게 문제가 생겨** 가족을 잃었다. 판타지 세계에서 불우한 전생을 살았던 주인공이 그곳에서 벗어나려고 「어떤 힘」을 써 현대세계에서 다시 태어났고, 그로 인해 겹침이 일어났다.

이 반전이 다시 쓰는 것:
- 겹침의 원인 = 주인공의 존재 자체
- 고아가 된 사고 = 주인공과 엮인 첫 번째 인연이 치른 값
- 반려자와 아이를 잃은 것 = 주인공이 옆에 있었기 때문
- 회귀를 찾는 여정 = 가족을 되찾으려는 여정이었는데, 되찾는 유일한 방법은 **자기가 없어지는 것**
- 주인공은 **두 번 도망쳤다**: 판타지 세계에서(그래서 겹침이 일어났다), 이 세계에서는 「회귀」라는 이름으로.

반전이 설명하는 것(마소 설정 포함): 주인공의 영혼이 판타지 세계의 영혼이므로 마소가 주인공에게는 이롭고 일반 사람에게는 해롭다. 마소의 해로움을 직접 설명하는 대사는 결말 전까지 없다(단서만).

**복선 후보(전부 결말 전엔 다르게 읽혀야 함):** 주인공만 마법 습득이 유난히 빠르다("환경이 바뀌어서"라고 거짓말) / 호의를 보인 NPC에게 나중에 안 좋은 일이 생긴다(반복되면 우연으로 안 읽힌다) / 판타지 주민 일부가 주인공을 알아보는 듯한 반응(요정, 설명 없음) / **짙은 마소 지역에서 주인공만 이상이 없다**(경계지·요정숲으로 확장) / 겹침 이전 기억의 구멍.

**일부러 빈칸으로 남기는 것(답이 없는 것):** 드워프 마을 주인들은 어디로 갔는가 / 던전 입구가 왜 아래로 내려가는 곳인가 / 판타지 세계에서의 전생이 정확히 어땠는가(「불우했다」까지) / 주인공이 쓴 「어떤 힘」이 무엇이었는가 / 되돌리는 것이 옳은가. 반전이 답하는 것(겹침의 원인, 주인공의 정체, 적대적인 존재가 사람을 고르는 이유)을 빈칸인 척하지 않는다.

위험: 단서가 너무 명확하면 반전을 일찍 추측하게 한다. 플레이테스트에서 "언제 이상함을 알아챘는가"를 측정한다.

### 결말 [확정: 두 갈래]
분기점은 **마지막 에피소드의 선택지 한 곳**이다. 그전까지는 갈라지지 않는다. 세이브는 어디서든 자유 — 분기 앞에 저장해 두고 양쪽을 다 볼 수 있다. 어느 쪽도 「좋은/나쁜 결말」로 그리지 않는다.
| 선택 | 결과 |
|---|---|
| **되돌린다** | 겹침이 없던 일이 된다. 주인공은 현대세계에 태어나지 않는다. 가족은 산다 — 주인공을 모른 채로. 그동안 만난 사람들, 지은 집, 요정숲이 된 아파트 단지도 함께 없던 일이 된다 |
| **되돌리지 않는다** | 세계는 이대로. 가족은 돌아오지 않는다. 주인공은 자기가 원인이라는 걸 알고 계속 산다. 지은 집도, 인연도 남는다 |
세 번째 갈래는 두지 않는다.

## 12. 기술

- **엔진: Unity 1순위, Godot 2순위, Unreal 3순위. P0 첫 4주 게이트에서 확정한다** [제안]. 근거: 젤다식 기조의 핵심이 렌더링이 아니라 자체 게임플레이 시스템이고, 저폴리곤이면 Unreal의 강점이 쓰이지 않는다. 발헤임의 엔진, 엔진별 라이선스, Unity/Godot의 대형 지형 스트리밍 사례는 **조사에 없어 확인 필요**.
- **엔진 게이트 통과 기준** [가정]: 최저 사양 기기에서 스트리밍 테스트 월드를 이동 중 히치 없이 통과 / 전투·주목 카메라를 하루 내에 수정·재실행 가능 / 지형 편집→배치→플레이 왕복 10분 이내. 못 통과하면 2순위 엔진으로 같은 테스트를 한 번 반복하고, 그래도 안 되면 월드를 "연결된 소규모 맵 여러 개"로 바꾼다.
- 스트리밍은 가장 큰 기술 리스크다. P0에서 먼저 측정한다.
- **데이터 중심:** 아이템·적·퀘스트·규칙표·대사를 엔진 밖 데이터 파일로 분리하고 현지화 키를 처음부터 붙인다. 대사 키마다 톤 메모와(미오는) 단계 번호를 붙인다.
- **세이브:** 버전 필드와 마이그레이션 훅, 어디서나 저장. 지형 변형은 델타만 저장하고 지도 데이터와 분리한다.
- **자동화·계측:** 빌드 서버, 맵 순회 봇, 규칙 조합 자동 테스트. 플레이 위치 히트맵, 이탈·사망 지점 로그.
- 현지화: 한국어 우선, 영어 병행. "들개" 같은 호칭의 영어 대응('strays' 계열), 반말의 시큰둥한 느낌, 숫자를 되뇌는 리듬은 번역 가이드가 필요하다.
- 모드: 출시 후 검토. 출시 전 공식 지원을 약속하지 않는다.

| P1 수직 슬라이스 | 6개월 | 한 지역을 완성 품질로, 제작 단가 실측 | 30~60분 플레이, 측정표 기록, 최저 사양 안정, 월드·퀘스트·던전 규모 확정 |
| P2 알파 | 10개월 | 전체 월드·던전·퀘스트 제작 | 엔딩까지 플레이 가능, 컷 목록 확정 |
| P3 베타 | 6개월 | 밸런스·UX·QA·접근성·최적화 | 치명 버그 0, 외부 플레이테스트 3회 |
| P4 출시/운영 | 5개월 | 출시 준비·출시·초기 패치 | 출시, 출시 후 3개월 계획 |
| 예비 | 4개월 | 지연 흡수 | — |

### 13.2 일정 경고
- 1인·외주 없음 전업 추산 약 45~51개월, **파트타임 주 20~30시간이면 약 60~102개월(5~8.5년)** 로 환산된다(단순 비례, 더 늘어날 수 있음). 사용자의 처음 목표 24~36개월을 크게 넘는다.
- 조사 문서에 1인으로 비슷한 규모를 2~3년에 완성한 사례는 없다(켄쇼: 사실상 1인으로 약 12년, R B.6).
- **일정 단축 방안(P0 프로토타입 결과를 본 뒤 결정 [확정])**: ① 1.0 범위 축소(4지역→2~3지역 등) ② 단계적 출시(코어 루프+첫 지역을 먼저, 요정숲·던전을 업데이트로 — 얼리 액세스 없음·약속 관리와 충돌 가능) ③ 기간 목표 변경(5~8년 전제) ④ 에셋 구매 허용(외주·구매 배제 결정을 수정). 그때까지는 현 범위(4지역, 전부 직접 제작)를 유지한다.

### 13.3 P0 프로토타입 요약
| | 질문 | 성공 기준 [가정] |
|---|---|---|
| A 전투 감 | 가볍게 이길 수 있는가 | 테스터 5명 중 4명이 설명 없이 회피·공격·주목 사용 |
| B 규칙 상호작용 | 전용 오브젝트 없이 해법이 둘 이상인가 | 데모 상황 3개 |
| C 이동 | 지형만 보고 오르고 싶은가 | 테스터 발언으로 나옴 |
| D 지형 변형 | 쌓고 깎기가 감당 가능한가 | 최저 사양에서 변형 중 30fps, 변형 100곳 저장·불러오기 후 용량 증가가 목표 이내, 스트리밍 경계에서 틈·튕김 없음. 건축물과의 상호작용, 대형 전투방 샘플 검증 포함 |
| 카메라 | 추격 카메라 비용이 감당 가능한가 | 충돌·변형 직후 보정·좁은 실내·주목 모두 동작 |

### 13.4 P1 수직 슬라이스 범위 [가정]
튜토리얼 통로 + 시가지 일부(1~2km²), 거점 1개, 필드 POI 15~25개, 소형 던전은 **대형 전투방 하나**로 지형 변형 공략 검증, 사이드 퀘스트 3개 중 **에닐의 열쇠 부탁과 1단계**로 인연 틀·대화 톤 검증. 측정표: 1km² 지형·POI·던전·퀘스트(+폐기율)·적/보스 제작 인일, 최저 사양 프레임, 용량(MB/km²), 플레이테스트 이탈 지점.

### 13.5 규모 가안 [가정, P1 측정 후 확정]
메인 1줄(8~12 구간), 사이드 20~30개(서브스토리 8개 포함, 폐기 전 1.3~1.5배 피치), 거점 NPC 15~25명, 몬스터 7종, 숙련도 레벨 5.

## 15. 결정 인덱스

결정 번호 1~71의 표는 `dev-spec-phases.md` **부록 B**에 있다(결정 번호와 영향 부록). 영역별 상세 근거: 규칙 D-6, 카메라 D-7, 예산·일정 D-8, 여주인공 D-9·D-11·D-16~D-19, 요정 D-10, 마소 D-12·D-14, 몬스터 D-13, 던전 D-15·D-20, 지도 D-21.

### 아직 정해지지 않은 것
- 한국 등급분류·심의비(확인하지 못함), 엔진 확정 후 라이선스 조건 재확인, 스팀 등록비 100달러 재확인(예산은 결정됨: 본업 병행·현재 장비·도구 월 5만 원 이하, 총 약 300~510만 원 상한)
- 일정 단축 방안(P0 프로토타입 결과 후)
- 대형 전투방의 세부 레이아웃(구덩이를 팔 수 있는 지면의 크기, 대형 이동 경로)과 구덩이에 빠진 대형의 무방비 시간
- 열쇠 부탁 보상의 구체 수량(채집 밀도 실측 후)
- 월드 크기 숫자(km², 지역별 치수; 방향은 "중간"으로 확정), 던전 해금 도구의 정식 이름·재료·획득 POI 위치, 낙반 제거 가능 지점의 수, 신호 장면의 내용·월드가 변하는 지점의 연출, 마지막 에피소드 시작 상호작용
- 제목, 최종 화풍 1안, 주인공 직업·이름(플레이어가 채움)

### 근거의 한계
- 월드 크기·퀘스트 수·인력 비율의 정량 기준, POI 간격·밀도 수치는 조사에서 확보하지 못했다.
- 발헤임의 엔진·제작 방식은 조사에 없고, "저용량 그래픽" 요건은 아트 방향 조사(R B.6 CEO 발언)에만 근거한다.
- 인터뷰·기사 내용은 대부분 요약 기사 기준이며 GDC 본문·Quantic Foundry 방법론·사르와르 인터뷰는 읽지 못했다(R 18.3 참조).
